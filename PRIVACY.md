# Privacy Policy — Hearth Universal

**Last updated:** October 2026

Hearth Universal is an open-source reference implementation submitted to the
Build, Ship, Shape: Amazon Developer Hackathon. It is a **demonstration
project**, not a commercial Alexa+ add-on.

## What this project does with your data

Hearth Universal is designed so that a judge can clone it and run it with **no
Amazon account, no AWS credentials, and no API keys**.

### Data you provide

- **Household simulation fixtures.** The demo ships with a synthetic household
  (residents Alex, Sarah, and Leo) and synthetic sensor telemetry. These are
  fictional and are not derived from any real person.
- **Statements you type into the demo.** If you submit private statements to the
  confidential family mediator (`POST /api/mediation/treaty`), they are processed
  in memory and are **never written to disk in plaintext**.

### What is persisted locally

Running the server creates a `state/` directory in your checkout containing:

| File | Contents |
|---|---|
| `state/audit.jsonl` | Append-only, HMAC-chained log of actions, actors, and decisions |
| `state/*.json` | Proposals, goals, memory entries, session memory |
| `state/synthesized_skills/` | Skills generated by the Meta-Skill Synthesizer |

You can delete this directory at any time; it contains no data from your machine
beyond what the demo itself wrote.

### Secrets

Vault placeholders (`{{vault:NAME}}`) are used for credentials. Secret values are
redacted before being persisted or passed to any model, and the Sentinel guardrail
denies any request that attempts to read or transmit raw credentials.

## Zero-knowledge mediation

The family mediator never discloses one resident's grievance to another. Raw
statements are reduced to weighted utility vectors, then discarded. Only
**salted SHA-256 digests** are retained, each with a per-resident random salt, so
identical text produces different digests for different residents. The mediator
also performs its bargaining computation in aggregate.

## Third-party services

Hearth Universal makes **no third-party network calls by default**. Specifically:

- **No telemetry, analytics, or tracking** of any kind.
- **Bedrock is opt-in.** With `AWS_BEDROCK_ENABLED=1` and AWS credentials
  present, prompts are sent to Amazon Bedrock in your own AWS account under your
  own IAM policy. Hearth stores no AWS credentials itself.
- **Web research tools are opt-in.** `web_search` / `web_fetch` are disabled
  unless you enable them and configure an allowlist.

## Data retention and deletion

All data is local to your checkout. To delete everything:

```bash
rm -rf state/
```
